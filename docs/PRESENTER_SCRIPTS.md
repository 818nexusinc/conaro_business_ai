# Presenter scripts (English and French)

_Generated by `npm run gen:assets` from `src/landing/agents-copy.ts`. Edit the scripts there, not here. French: review by a fluent reader required before publication._

One explainer per AI agent, in both languages. On the page each explainer **speaks**: a recorded file when one exists, otherwise the visitor's device reads the script with its most natural voice, with captions.

## What plays today

Every explainer ships with an **AI-generated voice** (Piper, open-source text-to-speech: English `en_US-ljspeech-high`, French `fr_FR-siwis-medium`; licences in docs/REFERENCE_CHECKS.md R66). Files: `public/audio/<lang>/<key>.mp3`, line timings in `src/landing/narration.ts`. After changing a script, regenerate them: `npx tsx scripts/export-scripts.ts > /tmp/scripts.json && python3 scripts/gen-narration.py <piper> <voices-dir> /tmp/scripts.json`.

## Recording natural voices (to replace the AI voice)

- **Who:** a real person (owner or staff, English and French speakers) or a natural neural voice service. Use a Canadian French voice for French. Never use a real person's voice or likeness without their written permission; label AI voices and avatars as AI.
- **Narration only (audio):** MP3, 44.1 kHz, mono, clear room. Files: `<lang>/<key>.mp3` (for example `fr/booking.mp3`). Set `BAI_PRESENTER_AUDIO_BASE` to the folder's address and redeploy.
- **Video explainers:** 1920×1080 MP4 (H.264, AAC) plus a 1280×720 JPG poster: `<lang>/<key>.mp4` and `<lang>/<key>.jpg`. Set `BAI_PRESENTER_VIDEO_BASE`. Video takes precedence over narration.
- **Words:** read the script exactly. Captions (`/captions/<lang>/<key>.vtt`) are generated from it; if you change the words, change them in `src/landing/agents-copy.ts` too.
- **Claims:** add no numbers, customer names, results or promises. Messages, posts and payments are not sent during the pilot.
