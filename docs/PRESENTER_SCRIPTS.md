# Presenter video scripts

_Generated by `npm run gen:assets` from `src/landing/presenters.ts`. Edit the scripts there, not here._

Seven short videos for the landing page. Each is about 25–35 seconds. The page already plays these lines as captions on an illustrated presenter card until a video exists.

## Recording

- **Presenter:** an AI avatar (HeyGen, Synthesia or similar) or a real person from the business. If an AI avatar is used, keep the on-screen label "AI presenter". Never use a real person's likeness without their written permission.
- **Format:** 1920×1080 MP4 (H.264, AAC), under 10 MB each if possible. Add a poster frame as a 1280×720 JPG.
- **Speech:** read each script exactly as written. The page's captions (`/captions/<id>.vtt`) are generated from these lines; if you change the words, change them in `src/landing/presenters.ts` too.
- **Claims:** add no numbers, customer names, results or promises that are not in the script. Messages, posts and payments are not sent during the pilot.
- **Publishing:** upload `<id>.mp4` and `<id>.jpg` to one public folder (for example Vercel Blob or the CONARO media host), set `BAI_PRESENTER_VIDEO_BASE` to that folder's address, and redeploy. Every presenter switches from the illustrated card to the video at once.
